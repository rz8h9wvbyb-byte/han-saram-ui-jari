# 웹전시 제작 기획서

# 「한 사람의 자리」

> 이 문서는 GitHub Pages 기반 디지털 전시 제작을 위한 기획서이다.
> 웹전시는 단순히 문화재를 소개하는 것이 아니라,
> **왕의 자리에서 느끼는 책임과 선택**을 관람자가 직접 체험하는 것을 목표로 한다.

---

# 1. 전시 기본정보

- 전시 제목 : 한 사람의 자리
- 팀명 : 디지털헤리티지 큐레이터 2기
- 작성자 : 김자경
- 전시 주제 :
  경복궁 근정전의 어좌를 중심으로,
  왕이 한 사람으로서 어떤 책임을 지고 있었는지를 체험하는 디지털 전시

- 전시 목적

관람자가 근정전을 단순한 건축물이 아닌

'한 나라의 모든 결정이 내려지던 공간'

으로 이해하도록 한다.

또한 왕이라는 존재를 권력자가 아닌

가장 큰 책임을 가진 사람으로 바라보도록 한다.

- 주요 관람자

조선 역사에 관심 있는 일반인

궁궐 관람객

학생

문화유산 교육 참가자

외국인 관광객

- 핵심 메시지

왕은 가장 높은 자리에 있었지만

동시에 가장 무거운 책임을 지고 있었다.

근정전의 중심에는 화려한 왕좌가 아니라

수많은 사람들의 삶을 결정하던

'한 사람의 자리'가 존재한다.

---

# 2. 전시 이야기

## 도입

광화문 앞.

관람자는 아직 궁궐 안으로 들어가지 않았다.

눈앞에는 조선의 정궁인 경복궁의 정문이 서 있다.

잠시 후

'입장하기'

버튼을 누르면

광화문 안으로 천천히 들어가며

왕이 걸었던 길을 따라가게 된다.

---

## 전개

첫 번째 전시에서는

광화문이 어떤 공간인지 소개한다.

궁궐의 시작이며

왕과 백성이 만나는 첫 관문이라는 의미를 설명한다.

두 번째 전시에서는

근정전을 소개한다.

조선의 국가 의례가 이루어졌으며

가장 중요한 정치 공간이라는 점을 보여준다.

세 번째 전시에서는

어좌를 관람한다.

왕이 실제로 앉던 자리가 아니라

왕이라는 역할을 상징하는 공간임을 설명한다.

네 번째 전시에서는

일월오봉도를 살펴본다.

해와 달

다섯 봉우리는

왕이 자연과 우주의 질서를 따라 나라를 다스려야 함을 상징한다.

다섯 번째 전시에서는

왕의 시선을 체험한다.

관람자는 어좌에서 바라본 근정전 내부를 보며

수많은 신하들을 마주하는 왕의 입장을 간접적으로 경험한다.

---

## 마무리

전시의 마지막에는

관람자에게 질문한다.

"당신이 이 자리에 앉는다면

어떤 선택을 하겠습니까?"

관람자는 자신의 다짐을 직접 입력한다.

입력된 다짐은

족자 위에 기록되고

마지막으로 왕의 옥새가 찍히며

전시는 마무리된다.

# 3. 전시 대상 구성

## 전시 대상 1 — 광화문

- 명칭 : 광화문
- 분류 : 경복궁 정문
- 주요 위치 : 경복궁 남측 정문
- 한 줄 설명 :
  조선의 법궁인 경복궁으로 들어가는 첫 번째 관문이다.

- 상세 설명

광화문은 경복궁의 정문이며,
왕과 신하, 백성이 모두 통과하던 공간이다.

이 전시는 광화문에서부터 시작된다.

관람자는 단순히 궁궐 안으로 들어가는 것이 아니라,
왕이 걸었던 길을 따라 근정전으로 향하게 된다.

광화문는 전시의 시작점이며,
현실에서 역사 속 공간으로 넘어가는 경계의 역할을 한다.

- 눈여겨볼 특징

  - 중앙 어도
  - 삼문 구조
  - 근정전으로 이어지는 축선
  - 궁궐의 시작이라는 상징성

- 사용할 이미지

  - 광화문 전경 이미지
  - 메인화면 배경 이미지

- 사용할 자료

  - 광화문 사진
  - 필요 시 Sketchfab 모델

조선에서 가장 중요한 국가 의례가 이루어지던 공간.

왕이 어떤 마음으로
이 공간에 앉아 있었는지에 초점을 둔다.

- 눈여겨볼 특징

  - 높은 기단

# 11. GitHub Pages 제작 조건

웹사이트는 GitHub Pages에서 서비스 가능한 정적 웹사이트로 제작한다.

필요한 파일 구성은 다음과 같다.

index.html

style.css

script.js

images/

README.md

필요 시

assets/

fonts/

폴더를 추가할 수 있다.

외부 라이브러리는 CDN 방식으로 불러온다.

---

## 반응형 지원

다음 환경에서 모두 사용할 수 있도록 제작한다.

- 데스크톱
- 태블릿
- 모바일

모든 버튼과 메뉴는 터치 조작이 가능해야 한다.

---

## 성능

페이지 로딩이 지나치게 오래 걸리지 않도록 한다.

이미지는 적절한 용량으로 사용한다.

애니메이션은 부드럽지만 과하지 않게 적용한다.

---

# 12. 디자인 원칙

이 웹전시는

"화려한 홈페이지"

가 아니라

"디지털 전시"

이다.

따라서

화려한 효과보다

몰입감을 우선한다.

관람자가

천천히

왕의 자리로 걸어가는 느낌을 받을 수 있도록 구성한다.

---

## 인터랙션 원칙

애니메이션은

느리고 부드럽게 진행한다.

불필요한 효과는 사용하지 않는다.

텍스트보다

이미지와 공간 경험을 중심으로 구성한다.

설명은 짧고 핵심적으로 작성한다.

---

# 13. Codex 제작 요청사항

이 문서와 준비된 이미지 및 Sketchfab 자료를 먼저 확인한다.

바로 코드를 작성하기 전에

웹사이트의 전체 구조를 먼저 계획한다.

다음 내용을 우선 설명한다.

1.

기획서를 어떻게 이해했는가

2.

전체 화면 구성을 어떻게 만들 것인가

3.

전시의 흐름을 어떻게 구현할 것인가

4.

Sketchfab 모델을 어디에 배치할 것인가

5.

애니메이션을 어떤 방식으로 구현할 것인가

6.

GitHub Pages에서 정상 동작하는지 확인할 방법

내가 계획을 확인한 뒤 제작을 진행한다.

# 14. 완료 확인

다음 항목을 모두 만족해야 한다.

□ 메인 화면이 정상적으로 표시된다.

□ 입장하기 버튼이 정상 동작한다.

□ 광화문 화면으로 이동한다.

□ 근정전 Sketchfab이 정상 출력된다.

□ 어좌 Sketchfab이 정상 출력된다.

□ 일월오봉도 Sketchfab이 정상 출력된다.

□ 상단 메뉴 이동이 정상 동작한다.

□ 이전 / 다음 버튼이 정상 동작한다.

□ 모바일에서도 화면이 깨지지 않는다.

□ 왕의 시선 이미지가 정상 출력된다.

□ 다짐 입력이 가능하다.

□ 족자가 펼쳐진다.

□ 입력한 문장이 족자에 표시된다.

□ 옥새 애니메이션이 실행된다.

□ 전시가 정상 종료된다.

□ GitHub Pages에서 정상 서비스된다.

# 15. 첫 제작 요청문

현재 폴더의

'한사람의자리_웹전시_기획서.md'

와

준비된 이미지 및 Sketchfab 자료를 확인해 주세요.

이 문서를 기준으로 GitHub Pages에서 서비스 가능한 디지털 전시를 제작하려고 합니다.

먼저

1. 기획서를 어떻게 이해했는지

2. 전체 화면 구성을 어떻게 설계할 것인지

3. 필요한 파일 구조

4. 사용될 기술

5. 구현 순서를 설명해 주세요.

그 후 실제 제작을 진행하겠습니다.

---

# 16. 제작 완료 후 검수 요청문

현재 제작된 웹전시를 기획서와 비교하여 전체 검수해 주세요.

다음 항목을 확인해 주세요.

- 전시 흐름이 올바른가

- 메인 화면이 정상 동작하는가

- Sketchfab 모델이 모두 정상 출력되는가

- 왕의 시선 체험이 자연스러운가

- 다짐 기능이 정상 동작하는가

- 족자와 옥새 애니메이션이 자연스러운가

- 모바일에서도 사용 가능한가

- GitHub Pages에서 오류 없이 실행되는가

문제가 있다면

기존 기획 의도를 유지하면서 수정해 주세요.

# 17. 프로젝트 목표

이 웹전시는 문화재를 소개하는 웹사이트가 아니라,

관람자가 왕의 자리에서 책임과 선택의 무게를 직접 느끼는 디지털 전시를 목표로 한다.

모든 화면은 이 목적을 중심으로 설계한다.
